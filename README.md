# Minha nova aba

1. Coloque o GIF que quiser no diretório do `index.html` e renomeie-o para `background.gif`.
2. Para mudar os atalhos, edite somente a lista JSON no final de `index.html`. Cada item tem um `nome` (exibido na tela) e uma `url` (o endereço aberto). O ícone principal é obtido automaticamente a partir do favicon do domínio; para isso, a página precisa estar com internet.

Instale a extensão **New Tab Override** ou programa semelhante, abra as opções dela e selecione **Custom URL**. Informe este endereço que quiser

Se preferir outro nome para o GIF ou imagem, mude a linha `--papel-de-parede` no começo do CSS em `index.html`.
