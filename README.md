# Minha nova aba

1. Coloque o GIF que quiser nesta pasta e renomeie-o para `background.gif`.
2. Abra `index.html` no Firefox para conferir.
3. Para mudar os atalhos, edite somente a lista JSON no final de `index.html`. Cada item tem um `nome` (exibido na tela) e uma `url` (o endereço aberto). O ícone principal é obtido automaticamente a partir do favicon do domínio; para isso, a página precisa estar com internet.

## Usar sempre ao abrir uma nova aba no Firefox

O Firefox não permite definir um arquivo HTML local como página de nova aba pelas configurações normais. Instale a extensão **New Tab Override**, abra as opções dela e selecione **Custom URL**. Informe este endereço, substituindo as barras caso necessário:

`file:///C:/Users/Marbons/Documents/GitHub/Pile/Outros/nova-aba/index.html`

Se preferir outro nome para o GIF, mude a linha `--papel-de-parede` no começo do CSS em `index.html`.
